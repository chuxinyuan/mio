## 关于 mio 量化交易系统

mio 是一个基于 R 的量化交易系统，以 **shinydashboardPlus（红色主题）+ ECharts** 构建，标的池为 **上证50（上交所）**。策略引擎沿用《Automated Trading with R》的组合模拟（`simulate`）与 MACD+Sharpe 排名逻辑，行情、交易、账户、日志统一存于 **SQLite 单文件**（`50_data/mio.db`）。

### 运行

```bash
# 1. 首次/更新数据（上证50 前复权日K 入库）
cd <项目根> && Rscript 00_fetch/refresh.R

# 2. 启动应用
Rscript -e 'shiny::runApp(".")'
# 或 RStudio 打开 mio.Rproj 后运行
```

### 功能模块

- **行情展示**：上证50 实时行情表 + 个股前复权 K 线（ECharts 蜡烛图，MA5/10/20 + 成交量副图，红涨绿跌）
- **策略控制**：MACD+Sharpe 参数面板、回测净值曲线与绩效、参数优化、今日信号
- **订单管理**：模拟下单/撤单、撮合成交、订单与成交回报
- **账户监控**：资金/总资产/持仓 valueBox、权益曲线、持仓明细与浮盈亏
- **系统日志**：数据刷新、下单成交、报错等事件日志

### 数据说明

- 数据源：东方财富免费 HTTP 接口（`secid` 前缀 `1.` = 上交所）
- 复权：前复权（`fqt=1`），更新行情采用**删旧插新**（前复权价格会随除权漂移）
- 标的池：动态获取上证50成分（`fs=b:BK0611`）
