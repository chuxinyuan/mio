## 关于 mio 量化交易系统

mio 是一个基于 R 的量化交易系统，以 **bs4Dash（深色赛博朋克主题）+ ECharts** 构建，标的池为 **上证50（上交所）**。策略引擎沿用《Automated Trading with R》的组合模拟（`simulate`）与 MACD+Sharpe 排名逻辑，行情、交易、账户、日志统一存于 **SQLite 单文件**（`50_data/mio.db`）。

### 运行

```bash
# 1. 首次/更新数据（上证50 后复权日K 入库，约 2-3 分钟）
just refresh

# 2. 运行单元测试（全部离线）
just test

# 3. 启动应用
just shiny
# 等价于 Rscript -e 'shiny::runApp(".")'
```

### 功能模块

- **行情展示**：上证50 实时行情表（15 分钟延时）+ 个股后复权 K 线（ECharts 蜡烛图，MA5/10/20 + 成交量副图，红涨绿跌）
- **策略控制**：MACD+Sharpe 参数面板、回测净值曲线与绩效、参数优化、今日信号、自动下单
- **订单管理**：模拟下单/撤单、按最新价撮合成交、订单与成交回报
- **账户监控**：资金/总资产/持仓 valueBox、权益曲线、持仓明细与浮盈亏
- **系统日志**：数据刷新、下单成交、报错等事件日志
- **系统设置**：交易/账户参数持久化（佣金、印花税、滑点、最大持仓等）

### 数据说明

- 数据源：历史日线以**腾讯 fqkline** 为主源（稳定），东方财富 push2his 为回退；行情（标的池/实时）走东方财富，主接口被限流时自动回退 **延时 15 分钟接口（push2delay）**
- 复权：**后复权（hfq）**——长史不会因累计分红取负，回测稳健（前复权 qfq 对高分红股长史会取负，破坏回测）；更新行情采用**删旧插新**（`replace_bars`）
- 标的池：动态获取上证50成分（`fs=b:BK0611`）
